其他项目怎么用

把 uni_modules/ 整个目录复制到目标项目根目录（与 pages.json 同级），重新编译即可。easycom 会自动扫描，模板里直接写标签：

<template>
  <kit-button type="primary" @click="save">保存</kit-button>
  <kit-tag type="success" text="已同步" />
  <kit-card title="说明">内容</kit-card>
</template>

无需 npm install、无需 import、无需 components 注册。也可以只拷某个 .vue 文件单独用。

分发物清单

  • index.js — npm / 显式 import 的聚合出口
  • scripts/gen-meta.js — npm run meta 生成组件元数据 / 文档
  • scripts/verify.js — npm run verify 自检
