## 搭建 uni-kit-ui 可复用 uni-app 组件库

需求：做一个组件项目，其他 uni-app 项目「直接用就行」，类似 Vue 单文件组件。

技术决策：
- 采用 **uni_modules + easycom** 作为主分发方式：目录规范
  `uni_modules/组件ID/components/组件名/组件名.vue` 会被自动扫描，模板直接写 `<kit-button>`，
  目标项目零 import / 零注册 / 零依赖。另提供「单 .vue 拷贝」与 npm 包两种接入方式。
- 统一 `kit-` 前缀；`pages.json` 加通配兜底 `"^kit-(.*)$": "@/uni_modules/kit-$1/components/kit-$1/kit-$1.vue"`。
- 每个组件单文件自包含：纯 CSS + `<style scoped>`、无外部 import、无 scss/less、无图片资源
  （empty 插图纯 CSS 绘制）、避免 currentColor / gap / inset 等小程序兼容差异。
- Vue2/Vue3 双兼容：Options API、显式声明 `emits`、弹窗做受控组件（`show` + `update:show`），
  不用 `v-model:show` 作为唯一写法。
- 按钮默认 `inline-flex`（否则非 flex 容器里会占满整行），`block` 时改 `display:flex; width:100%`。

产出文件：
- `uni_modules/` 下 5 个组件：kit-button / kit-tag / kit-card / kit-empty / kit-dialog
  （每个含 .vue + package.json + readme.md）
- 根 `index.js`（聚合导出 + install）、`package.json`、`README.md`（三种接入方式 / API / 多端约定 / 新增组件步骤）、`CHANGELOG.md`
- `pages/index/index.vue` 改为可交互组件画廊；`pages.json` 加 easycom 规则
- `scripts/verify.js` 零依赖自检（结构/JSON/scoped/自包含/emits/JS 语法/标签配对），`npm run verify`
- `scripts/pack.js` 零依赖 ZIP(store) 打包，`npm run zip`；Windows Compress-Archive 包内是反斜杠，
  在 macOS/Linux 解压会坏，所以自写脚本强制正斜杠路径
- `preview.html` 静态外观速览（rpx 按 1rpx=0.5px 换算，非组件本体）
- `uni-kit-ui-uni_modules.zip` 分发包（15 个文件，已用 `unzip -t` 校验）

验证：`npm run verify` 全项通过；zip 用 `unzip -t` 通过。
未做真机/多端编译验证（环境无 HBuilderX / uni-app CLI），README 中已如实说明。

## 1.1.0 扩充到 28 个组件（用户反馈「5 个不够用」）

- 新增 23 个：表单 8（input/textarea/search/switch/stepper/rate/radio/checkbox）、
  反馈 6（toast/loading/popup/action-sheet/notice-bar/progress）、
  展示 4（badge/icon/avatar/divider）、导航状态 5（cell/tabs/steps/load-more/skeleton）。
- **关键约定：Vue2/Vue3 双兼容 v-model** —— props 同时声明 `value` 与 `modelValue`，
  computed `current` 取 `modelValue ?? value`，变化时同时 emit
  `input` / `update:modelValue` / `update:value` / `change`。
  分组组件（radio/checkbox/tabs/steps/action-sheet）一律用 options 数组，
  不用 $parent / provide-inject，规避小程序端跨组件通信差异。
- 新增 `scripts/gen-meta.js`：组件清单 C 数组（28 行元数据）+ 从 .vue 解析
  props/emits/slots → 自动生成 package.json 与 readme.md，默认只补缺失文件（幂等），
  `--force` 全量重建。`npm run meta`。
- `index.js` 补齐 28 个导出；演示页改为 kit-tabs 分类画廊；README 加 28 个组件总表与
  双兼容 v-model 说明；preview.html 加完整组件清单；CHANGELOG 1.1.0。
- 最终验证：`npm run verify` 28/28 全通过；`npm run zip` 生成 84 文件 / 131 KB，
  `unzip -t` 无错误。仍只做静态检查，未多端编译。
- 修过的两个小坑：kit-radio 的 dotStyle 曾误写未定义函数 `currentOf(this)`；
  :first-child / :active 等结构伪类改为显式 class，避免小程序 WXSS 不支持。
